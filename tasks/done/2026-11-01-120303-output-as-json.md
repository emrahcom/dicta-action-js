# Output as JSON

The client turns a capability's output into JSON as soon as `run` returns, as
`contract-capability.md` (Capabilities, `run`) in `dicta-action-server`
describes.

- References and the report use only that JSON value; `undefined` becomes
  `null`, and a `Date` its JSON string.
- A value that cannot be turned into JSON, such as a cyclic object, fails the
  step with `capability`, in a call step and in a `forEach`.
- The output is not checked against `output`.
- Unit tests: `undefined` and a `Date` as outputs, seen through a reference and
  in the report; a cyclic output halts with `capability` at its step.
