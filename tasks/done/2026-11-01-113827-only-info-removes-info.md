# Only an info removes an info

When a fourth notice would be shown, the element follows `architecture.md`
(Display): the oldest that goes away by itself goes first, and only an info
removes an info.

- With three infos shown, a new info removes the oldest info.
- With three infos shown, a notice that goes away by itself is shown as a fourth
  until it goes.
- A new info while that fourth is shown removes it and then the oldest info.
- Browser tests for the three cases.
