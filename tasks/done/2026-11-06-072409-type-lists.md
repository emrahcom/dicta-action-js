# Type lists

Accept a list of types in capability schemas, as `contract-capability.md`
(Capabilities) in `dicta-action-server` describes.

- The exported `Schema` type in `src/module.ts` lets `type` be one type or a
  list of them, so a module can write `type: ["string", "null"]`.
- The argument check in `src/plan.ts`, before the plan runs and again once the
  references are filled in, lets a value pass a type list when it matches any
  type in it. The error names all the types, as the server's does, such as
  `steps[0].args.due must be of type string or null`.
- Tests for: a plan argument that matches the first type of a list, the second,
  and neither; `null` in an argument whose type is only `string`, still refused;
  a reference filled in with `null` for a type list, accepted when the step
  runs.
