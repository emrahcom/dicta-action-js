# Escaped dollar

The plan check compares a string written with `$$` with its schema as the
capability gets it, with a single `$` (`contract-plan.md` in
`dicta-action-server`, References).

- In the check before the run, the `enum` check takes a `$$` string with one `$`
  removed. The check after references are filled in is unchanged, since the
  value there already has a single `$`.
- Tests: a plan with `"$$USD"` against `enum: ["$USD"]` passes the check and the
  capability gets `"$USD"`; `"$$USD"` against `enum: ["$$USD"]` fails.
