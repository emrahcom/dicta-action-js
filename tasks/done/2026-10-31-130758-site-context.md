# Site context

Build the site context from the capability module, as `architecture.md`
(Element, `module`) and `contract-context.md` in `dicta-action-server` (Fields)
describe.

- TypeScript types for the module and its capabilities, as
  `contract-capability.md` (Module, Capabilities, State) describes, exported
  from `src/index.ts` for module authors.
- A function that takes the module and returns the site context: `site` as it
  is, `state` with the state's `desc`, and `capabilities` with one entry for
  each capability, in the module's order, with its `name`, `level`, `desc` and,
  when set, `args` and `output`. `run`, `confirm` and `confirmOver` are left
  out.
- No checks of the module: the server checks the context (`contract-context.md`,
  Checks).
- Unit tests: a module with a capability with `args` and `output`, one without
  both, and the functions left out.
