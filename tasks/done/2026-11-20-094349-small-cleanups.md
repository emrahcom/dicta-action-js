# Small cleanups

Code quality fixes from the review of 2026-11-20, with no change in behaviour
and no move between files. `runPlan` and the file split come in a later task.

- `src/plan.ts`: one helper for an optional text of at most N code points, used
  for the label, a step's text and the progress, as in the server's copy
  (`dicta-action-server/src/plan.ts`). "a plan is at most 16 KB" uses its
  constant.
- One helper turns a thrown value into its message, used where `element.ts` and
  `run.ts` write it out today and in place of `message()` in `round.ts`.
- `src/element.ts`:
  - one helper builds a `text` element, and `#button` also takes a part and a
    label, so the option buttons use it;
  - one helper checks whether an element holds the focus;
  - the running plan and its progress are reset once, in a `finally`;
  - the oldest notice to drop is picked with plain if/else, not a nested
    ternary;
  - fields first, then the lifecycle callbacks together, then the rest.
- `src/run.ts`:
  - `reportSoFar` becomes `cancelledReportSoFar(progress)`, its only use, and
    `STOP_MESSAGES` is no longer exported if nothing else needs it;
  - `bytes` is no longer exported;
  - the constants and the types go to the top.
- `src/builtins.ts`: `capabilityError` and `ENTRY_PROPERTIES` are inlined at
  their one use, and the outcome types come from one list shared with
  `history.ts`.

Tests: the existing tests pass, changed only where a name changes.

Check: `npm run check`, `npm run lint`, `npm run test`, `npm run test:browser`
and `npm run build` pass.
