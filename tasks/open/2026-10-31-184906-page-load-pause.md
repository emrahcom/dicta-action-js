# Page load pause

A step that starts a page load returns, and the element waits for the page to be
left, as `architecture.md` (Requests, Display, Plan runner, Storage, Strings)
and `contract-protocol.md` and `contract-capability.md` in `dicta-action-server`
(Added text and cancel, Page changes) describe.

- A `navigate` listener of the Navigation API notes a page load: an event whose
  `destination.sameDocument` is false. Without the Navigation API, nothing is
  noted and the runner goes on.
- The runner checks for a page load after each step, and in a `forEach` after
  each call, since that step or call started. On one it stops and makes the
  report: the halt code `navigated` at the first step that did not run, with
  `item` and `do` in a `forEach`, or no halt when none is left.
- The element then holds the report, does not send it and keeps the `working`
  view with Cancel.
- From the start of a page load during a request until the page is left,
  `submit` ignores the text and shows the `pageLoad` notice. Text that came
  before the page load started stays added text.
- On `pagehide`, the request is saved only while the element waits for a page
  load: the exchange, the plan, its report and the added text. A page load at
  any other time, also while a step still runs, ends the request as cancelled.
- A saved request that goes on sends its report followed by its added text; an
  older one is stored as cancelled with them.
- Cancel while the element waits for a page load stores the request as cancelled
  with the report it holds and the added text.
- A new string, `pageLoad`: "Wait for the page to load".
- Test capabilities that load a page return after starting it, with no
  never-settling promise (`test/browser/server.ts`,
  `test/browser/confirmations.spec.ts`).
- Browser tests in the three engines: a page-loading step as the last step (no
  halt) and in the middle (`navigated` at the next step) going on in the new
  page; a page load in a `forEach` call; text ignored with the notice during the
  pause; added text from before the page load sent from the new page; Cancel
  during the pause stored with its report; a hash change that does not pause the
  runner. Check how a "Stay" at the browser's leave prompt behaves, and report
  it.
