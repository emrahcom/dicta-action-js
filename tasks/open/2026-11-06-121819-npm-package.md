# npm package

Make dicta-action-js ready to publish to npm, per `architecture.md`
(Delivery).

- `package.json`: remove `"private": true`; add `description`, `keywords` and
  `repository`; add a `prepublishOnly` script that builds a clean `dist/`, so no
  stale file is published.
- Check with `npm pack --dry-run` that the package holds only `dist/`,
  `README.md`, `LICENSE` and `package.json`.
- `README.md`: what dicta-action-js is, how to install it from npm, and a short
  example page with `<dicta-action>` and its `server`, `getToken` and `module`
  properties. It points to `dicta-action-harness` for writing a capability
  module and to the specs for the details.
- `docs/releasing.md`, the same steps as in `dicta-js`: the version number
  rules while the major number is 0, the checks, the release commit, the tag,
  the GitHub release, then `npm publish` from the release commit. The first
  release is `0.1.0`.
