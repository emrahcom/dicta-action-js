# Tab id

Every round sends `tabId` (`architecture.md`, Requests and Storage;
`contract-protocol.md` in `dicta-action-server`, Request body).

- Before the first round, the element reads `dicta-action-tab-id` from session
  storage. When none is stored, it makes one, 16 bytes from
  `crypto.getRandomValues()` in hex, and stores it.
- When storage cannot be read or written, the element makes one and keeps it in
  the page's memory, and the round goes on.
- Every round of every request of the tab sends the same `tabId`, also after a
  page load.

Tests: unit tests for the id: 32 hex characters, the same id on a second read,
and an id in memory when storage throws. A browser test: two requests send the
same `tabId`, and a request that goes on after a page load keeps it.

Check: `npm run check`, `npm run lint`, `npm run test`, `npm run test:browser`
and `npm run build` pass.
