# Focus return

When a view goes away while the focus is in it and no view follows, the focus
goes back to where it came from, as `architecture.md` (Accessibility) describes.

- When the focus moves into the view from a page element outside the
  `<dicta-action>` element, the element remembers that page element.
- When a view goes away with the focus in it and no view follows (Cancel, Close,
  a done), the focus goes back to the remembered element. If it is gone from the
  page, the focus goes to the `<dicta-action>` element itself, with
  `tabindex="-1"`.
- A new view still moves the focus to its Cancel or Close, as before.
- Browser tests: the focus goes back to the site's text field after Cancel in
  `working` and after Close on a stop; to the element when the text field was
  removed; and stays where it is when it was not in the view.
